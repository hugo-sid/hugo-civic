## उपयोग

```
{{</* alert type="warning" title="Check your version" */>}}
Body copy, written as **markdown**.
{{</* /alert */>}}
```

{{< alert type="warning" title="अपना संस्करण जाँचें" >}}
मुख्य पाठ, **मार्कडाउन** के रूप में लिखा गया।
{{< /alert >}}

## पैरामीटर

| पैरामीटर | मान | डिफ़ॉल्ट |
|---|---|---|
| `type` | info, warning, error, success, emergency | info |
| `title` | कोई भी पाठ | कोई नहीं |
| `slim` | true | false |
| `no_icon` | true | false |

## किसका उपयोग कब करें

`slim` का उपयोग केवल तभी करें जब संदेश एक छोटी पंक्ति हो — इस वैरिएंट में कोई शीर्षक
स्लॉट नहीं है और यह पैडिंग आधा कर देता है, इसलिए इसमें एक रैप्ड पैराग्राफ़ असंतुलित
दिखता है।

ऐसे पृष्ठ पर `role` को अनसेट छोड़ें जो बिल्ड समय पर अलर्ट रेंडर करता है। `role="alert"`
सेट करने से स्क्रीन रीडर पृष्ठ लोड होते ही जो कुछ भी पढ़ रहा था उसे बाधित कर देता है,
जो किसी उपयोगकर्ता कार्रवाई के बाद इंजेक्ट की गई चीज़ के लिए सही है और स्थिर पाठ के
लिए ग़लत।
