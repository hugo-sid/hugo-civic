ஒரு அக்கார்டியன் இரண்டு ஷார்ட்கோடுகளால் ஆனது: குழுவின் அமைப்புகளைச் சுமக்கும் ஒரு
வெளிப்புற ஷார்ட்கோடு, பின் ஒவ்வொரு பலகத்திற்கும் ஒரு உள் ஷார்ட்கோடு.

{{< accordion-item title="bordered என்ன மாற்றுகிறது?" expanded="true" >}}
ஒவ்வொரு பலகத்தையும் சுற்றி ஒரு விளிம்பை வரைகிறது. அக்கார்டியன் ஒரு அட்டைக்குள்
இல்லாமல் நேரடியாகப் பக்கப் பின்னணியில் அமரும்போது இதைப் பயன்படுத்துங்கள்.
{{< /accordion-item >}}
{{< accordion-item title="multiselectable என்ன மாற்றுகிறது?" >}}
ஒன்றுக்கு மேற்பட்ட பலகங்களை ஒரே நேரத்தில் திறந்து வைக்க அனுமதிக்கிறது. இது
இல்லாவிட்டால், ஒரு பலகத்தைத் திறந்தால் மற்றவை மூடிக்கொள்ளும்.
{{< /accordion-item >}}
{{< accordion-item title="heading_level ஏன் அமைக்க வேண்டும்?" >}}
உருப்படிகள் இயல்பாக `h4` ஆக இருக்கும். ஒரு `h2` இன் கீழ் நேரடியாக வரும்போது அது
ஒரு நிலையைத் தவிர்க்கிறது, எனவே ஆவணத்தின் தலைப்பு வரிசை தொடர்ச்சியாக இருக்கும்படி
நிலையைக் கொடுங்கள்.

பக்கத்தில் பல அக்கார்டியன்கள் இருந்தாலும் ID கள் மோதிக்கொள்ளாது.
