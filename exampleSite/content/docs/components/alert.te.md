## వాడకం

```
{{</* alert type="warning" title="Check your version" */>}}
Body copy, written as **markdown**.
{{</* /alert */>}}
```

{{< alert type="warning" title="మీ వెర్షన్‌ను సరిచూసుకోండి" >}}
**మార్క్‌డౌన్‌లో** రాసిన వచనం.
{{< /alert >}}

## పరామితులు

| పరామితి | విలువలు | డిఫాల్ట్ |
|---|---|---|
| `type` | info, warning, error, success, emergency | info |
| `title` | ఏ వచనమైనా | ఏదీ లేదు |
| `slim` | true | false |
| `no_icon` | true | false |

## ఏది ఎప్పుడు వాడాలి

సందేశం ఒకే ఒక చిన్న పంక్తి అయినప్పుడు మాత్రమే `slim` ను వాడండి — ఆ రూపానికి
శీర్షిక స్థానం ఉండదు, లోపలి ఖాళీ కూడా సగానికి తగ్గుతుంది, కాబట్టి పలు పంక్తులకు
సాగే పేరా అందులో సమతూకం లేకుండా కనిపిస్తుంది.

బిల్డ్ సమయంలోనే అలర్ట్‌ను రెండర్ చేసే పేజీలో `role` ను అమర్చకుండా వదిలేయండి.
`role="alert"` అని అమర్చితే, పేజీ లోడ్ అయిన క్షణంలోనే స్క్రీన్ రీడర్ తాను
చదువుతున్నదాన్ని మధ్యలోనే ఆపేస్తుంది — ఇది వినియోగదారు చర్య తర్వాత చేర్చే
వచనానికి సరైనది, స్థిరమైన వచనానికి తప్పు.
