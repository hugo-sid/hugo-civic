## இதை இயக்குவது

இது ஒரு ஷார்ட்கோடு அல்ல, முன்தகவல்:

```yaml
in_page_nav: true
in_page_nav_headings: "h2"
```

ஒரு ஷார்ட்கோடு `main` இனுள் மட்டுமே உருவாக முடியும்; ஆனால் இந்தக் கூறு `main`
இன் அருகில் அமர வேண்டும், அப்போதுதான் இரண்டும் பக்கவாட்டில் அமையும். அந்த
முடிவை நேரத்தில் எடுக்கக்கூடிய ஒரே இடம் முன்தகவல்தான்.

## எந்தத் தலைப்புகள் என்பதைத் தேர்வு செய்தல்

USWDS இயல்பாக `h2` மற்றும் `h3` இரண்டையும் ஆராய்கிறது; அது *கூறுகளுக்கு*
உரிய தலைப்புகளையும் அள்ளிக்கொள்கிறது — ஒரு சுருக்கப் பெட்டியின் `h3`, ஆவணத்தின்
ஒரு பிரிவைப் போலவே பட்டியலில் தோன்றிவிடும். கூறுகளைப் பயன்படுத்தும் பக்கத்தில்
இதை `h2` ஆகச் சுருக்குங்கள்.

| அளபுரு | விளைவு |
|---|---|
| `in_page_nav_headings` | எந்த நிலைகளை ஆராய்வது |
| `in_page_nav_title` | பட்டியலுக்கு மேலுள்ள தலைப்பு |
| `in_page_nav_min_headings` | இந்த எண்ணிக்கைக்குக் கீழ் மறைத்துவிடும் |

இந்தப் பட்டியல் உருவான தலைப்புகளிலிருந்து JavaScript மூலம் கட்டப்படுகிறது, எனவே
JavaScript இல்லாதபோது பட்டியலும் இல்லை — அதுவே சரி, ஏனெனில் தலைப்புகள்
அப்படியே, அதே வரிசையில், இன்னும் அங்கேயே இருக்கின்றன.
