இந்தப் பாதை பக்கத்தின் மூதாதையர் வரிசையிலிருந்து உருவாக்கப்படுகிறது, எனவே இதற்கு
எந்த அமைப்பும் தேவையில்லை. தற்போதைய பக்கம் `aria-current="page"` சுமக்கும் ஒரு
`span` ஆகவே இருக்கும், ஒருபோதும் இணைப்பாக இருக்காது — நீங்கள் இருக்கும்
பக்கத்திற்கே ஒரு இணைப்பு என்பது முட்டுச்சந்து.

மேல் நிலையில் வழித்தடம் எதையும் காட்டுவதில்லை. ஒரே ஒரு உள்ளீடு கொண்ட பாதை
வெறும் இரைச்சல்.

ஒவ்வொரு பாதையும் schema.org இன் `BreadcrumbList` தரவையும் வெளியிடுகிறது; அது
உருவாக்க நேரத்தில் எந்தச் செலவும் இல்லாதது, தேடல் முடிவின் கீழே தெரியும் பாதையை
உருவாக்குவதும் அதுதான். இதை நிறுத்த:

```toml
[params.uswds.breadcrumb]
  metadata = false
```
