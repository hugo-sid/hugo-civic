## దీన్ని ప్రారంభించడం

ఇది ఫ్రంట్ మేటర్, షార్ట్‌కోడ్ కాదు:

```yaml
in_page_nav: true
in_page_nav_headings: "h2"
```

ఒక షార్ట్‌కోడ్ `main` లోపల మాత్రమే రెండర్ కాగలదు; ఈ రెండూ పక్కపక్కనే
అమరాలంటే ఈ కాంపోనెంట్ `main` కు తోబుట్టువుగా ఉండాలి. ఈ నిర్ణయాన్ని సకాలంలో
తీసుకోగలిగే ఏకైక చోటు ఫ్రంట్ మేటర్.

## ఏ శీర్షికలను ఎంచుకోవాలి

USWDS డిఫాల్ట్‌గా `h2`, `h3` రెండింటినీ స్కాన్ చేస్తుంది; దానివల్ల
*కాంపోనెంట్‌లకు* చెందిన శీర్షికలు కూడా లోపలికి వచ్చేస్తాయి — ఒక సారాంశ పెట్టెలోని
`h3` పత్రంలోని ఒక విభాగంలా కనిపిస్తుంది. కాంపోనెంట్‌లు వాడే పేజీలో దీన్ని `h2`
కే పరిమితం చేయండి.

| పరామితి | ప్రభావం |
|---|---|
| `in_page_nav_headings` | ఏ స్థాయిలను స్కాన్ చేయాలి |
| `in_page_nav_title` | జాబితా పైన ఉండే శీర్షిక |
| `in_page_nav_min_headings` | ఈ సంఖ్య కంటే తక్కువైతే దాచు |

రెండర్ అయిన శీర్షికల నుండి ఈ జాబితాను JavaScript తయారు చేస్తుంది, కాబట్టి JS
ఆపివేసి ఉంటే జాబితా ఉండదు — అది సరైనదే, ఎందుకంటే శీర్షికలు మాత్రం అక్కడే,
అదే వరుసలో ఉంటాయి.
