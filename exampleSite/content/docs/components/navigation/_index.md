None of these are shortcodes. Each one is derived from the site's structure —
the section tree, the page's ancestry, or the headings in the body — so there is
nothing to write in the markdown and nothing to keep in sync by hand.

This subsection also exists to prove the point the side navigation page makes:
the tree you are looking at on the left is three levels deep, and it opened
itself.
